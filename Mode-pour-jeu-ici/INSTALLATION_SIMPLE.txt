DonJ Custom NPC Placer Enhanced - installation simple
======================================================

Ce guide est integre au package game-ready genere et verifie par la CI.
N'utilisez jamais un ancien binaire conserve manuellement dans le depot source.

Ou obtenir le package
---------------------

1. Ouvrez l'onglet Actions du depot GitHub.
2. Ouvrez la derniere execution Safety reussie dont la branche est main et
   l'evenement push. Une execution de pull request ou d'une autre branche n'est
   pas une release installable.
3. Telechargez l'artefact DonJCustomNpcPlacer-game-ready.
4. Decompressez-le avant de suivre les etapes ci-dessous.
5. Ouvrez manifest.json et verifiez que manifestVersion vaut 2, que sourceDirty vaut false,
   que scriptApi.major vaut 2, que scriptApi.abiContract.sha256
   contient 64 caracteres hexadecimaux et que commit correspond au dernier
   commit de main.

Fichiers inclus
---------------

- DonJCustomNpcPlacer.ENdll
  Obligatoire. C'est le fichier du mod.

- DonJCustomNpcPlacer.pdb
  Optionnel. Il sert surtout au debug et rend les logs plus lisibles.
  Vous pouvez le copier aussi, ca ne gene pas.

- manifest.json
  Il indique le commit, la version de l'API ScriptHookVDotNet ciblee, l'empreinte
  du contrat ABI NIB, les autres versions, les tailles et les SHA-256 exacts du
  binaire et du PDB issus du meme build teste. Copiez-le dans Scripts en le renommant
  DonJCustomNpcPlacer.manifest.json pour le diagnostic du mod.

- INSTALLATION_SIMPLE.txt
  C'est ce guide. Il reste hors de Scripts.

Ou mettre les fichiers
----------------------

1. Fermez GTA V Enhanced.

2. Ouvrez le dossier principal de GTA V Enhanced.
   C'est le dossier ou se trouve GTA5_Enhanced.exe.

   Exemple Steam :
   C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V Enhanced

3. Dans ce dossier, ouvrez le dossier Scripts.

   Exemple :
   C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V Enhanced\Scripts

4. Copiez dans Scripts :

   - DonJCustomNpcPlacer.ENdll
   - DonJCustomNpcPlacer.pdb  (optionnel)
   - manifest.json, renomme DonJCustomNpcPlacer.manifest.json

Important
---------

Ne copiez pas le dossier du package entier dans Scripts.
Copiez uniquement DonJCustomNpcPlacer.ENdll, le manifest renomme et, si vous le
souhaitez, le PDB fourni dans ce meme package verifie.

Ce qu'il faut avoir avant de lancer le jeu
-----------------------------------------

Sous Windows, Microsoft .NET Framework 4.8 doit etre installe.

Dans le dossier principal de GTA V Enhanced, au meme niveau que GTA5_Enhanced.exe,
vous devez avoir :

- ScriptHookV.dll
- xinput1_4.dll
- NIBScriptHookVDotNet.asi
- NIBScriptHookVDotNet2.dll

Dans le dossier Scripts, vous devez avoir :

- DonJCustomNpcPlacer.ENdll
- DonJCustomNpcPlacer.manifest.json

Lancer le mod
-------------

1. Lancez GTA V Enhanced en mode histoire.
2. Appuyez sur F10 pour ouvrir le menu du mod.
3. Pour appeler le Cartel allie : ouvrez le telephone du joueur, affichez les contacts
   du mod, puis appuyez sur C.
4. Pour lancer une attaque Ballas hostile : gardez le telephone ouvert et appuyez sur R.
5. Pour ramasser un objet argent interactif : approchez-vous du cash et appuyez sur E.

Mise a jour du mod
------------------

1. Fermez le jeu et ses loaders.
2. Verifiez le SHA-256 du nouveau DonJCustomNpcPlacer.ENdll avec manifest.json.
3. Copiez DonJCustomNpcPlacer.ENdll et, si souhaite, DonJCustomNpcPlacer.pdb
   depuis le package game-ready verifie en remplacant les fichiers du meme nom.
   Ne supprimez jamais l'ancien ENdll avant d'avoir valide le nouveau fichier a
   copier.
4. Remplacez Scripts\DonJCustomNpcPlacer.manifest.json par le manifest.json du
   meme package, en conservant ce nom stable.
5. Recalculez le SHA-256 du ENdll installe et comparez-le encore au manifest.
6. Seulement apres cette validation, retirez les anciens alias listes ci-dessous.
7. Relancez le jeu.

Si vous aviez une ancienne version
----------------------------------

Supprimez les anciens fichiers s'ils existent :

- Scripts\DonJCustomNpcPlacer.dll
- Scripts\DonJEnemySpawner.dll
- Scripts\DonJEnemySpawner.ENdll
- Scripts\DonJEnemySpawner.pdb

Cela evite que deux versions du script se chargent en meme temps.

Attention
---------

Ce mod est fait pour le mode histoire / solo uniquement.
Ne l'utilisez pas dans GTA Online.

Desinstallation
---------------

1. Fermez GTA V Enhanced et ses loaders.
2. Supprimez dans Scripts :
   - DonJCustomNpcPlacer.ENdll
   - DonJCustomNpcPlacer.pdb, s'il est present
   - DonJCustomNpcPlacer.manifest.json
3. Les sauvegardes DonJEnemySpawnerSaves peuvent etre conservees ou supprimees
   separement.
